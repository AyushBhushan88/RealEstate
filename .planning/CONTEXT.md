# Project Context: Real Estate Management System (REMS)

## Core Technical Stack
- **Frontend**: React/Next.js (TypeScript)
- **Backend**: Node.js/Express
- **Database**: PostgreSQL (Prisma ORM recommended)
- **Styling**: Vanilla CSS (Preferred)
- **Authentication**: Email/Password + Google OAuth

## Business Context
REMS is a comprehensive platform for real estate agencies to manage the entire property lifecycle, from listing to closing. It supports multiple user roles (Admin, Agent, Owner, Buyer, Tenant, Account Manager) and integrates features like e-signatures and live payments.

## Key Stakeholders & Roles
| Role | Responsibility |
|------|----------------|
| Admin | Platform-wide management and analytics |
| Agent | Listing management, lead tracking, and transaction handling |
| Owner | Property ownership and status tracking |
| Buyer/Tenant | Searching, viewing, and booking properties |
| Account Manager | Commission and transaction split tracking |
